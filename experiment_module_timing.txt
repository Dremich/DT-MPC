Notes
- The two DDP solves dominate; both scale roughly linearly with the horizon N
  (backward Riccati + line-search rollouts are O(N)). The nominal solve has a
  fixed goal reference so its XLA executable is reused every step; the ancillary
  reference changes each step but keeps the same shapes, so it stays compiled.
- The DOC hypergradient (Alg.1) is a CPU/numpy + JAX-dispatch pass; 'assemble'
  (per-step jacobians_fn / jacobian_wrt_theta / cost derivs) is its main cost,
  while the backward/forward Riccati recursions are small numpy loops.
- Bookkeeping (ref update, Eq.9 loss, theta update) is negligible (<1% of a step).
